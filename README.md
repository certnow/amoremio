# Amoremio

Base visual do site Amoremio, construída em etapas estáveis.

## Escopo atual

- fachada em tela cheia;
- duas cortinas translúcidas;
- abertura por clique;
- vitrine editorial atrás da cortina;
- resposta sutil ao movimento do ponteiro;
- adaptação para celular e movimento reduzido.

O projeto não inclui menu, catálogo, carrinho ou integrações de loja nesta etapa.
